            새 프로젝트

            어떤 프로젝트를 검사할까요?

            Git 저장소는 현재 커밋을 검사하며 미커밋 변경은 제외합니다.

            GitHub 주소는 이 PC에 복제하고, 스캔 전 최신 커밋을 가져옵니다.

            일반 폴더는 원본을 바꾸지 않고 현재 파일의 스냅샷을 검사합니다.

            설정

            01 / 계정

            ChatGPT 연결

            AI 분석은 비밀값을 가린 코드 일부를 전송하며 구독 사용량이 차감됩니다. 사용량은 ChatGPT 설정에서 관리하세요.

            먼저 터미널에서 python -m vibescan.register를 실행해 이 PC를 등록하세요.

            02 / 자동 감시

            프로젝트 선택 필요

            전체 프로젝트 공통 · 새로 생긴 치명·높음 발견만 검토합니다.
